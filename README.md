## 👋 About me

I'm **Sunnatbek Yusupov** — a frontend engineer and the **Founder & CEO of [Aidevix](https://aidevix.uz)**, the first AI-first programming education platform built for the Uzbek-speaking world.

- 🔭 &nbsp;I'm building **[Aidevix](https://aidevix.uz)** — teaching developers to ship real products with AI tools like Claude Code, Cursor and GitHub Copilot.
- 🎯 &nbsp;**Mission:** prepare **100,000+ AI-fluent developers** across Uzbekistan by 2030.
- 💻 &nbsp;Day-to-day I work with **React, Next.js, TypeScript** and modern web architecture.
- 🌱 &nbsp;Currently going deeper into **AI agents, LLM tooling and scalable EdTech systems**.
- 🌍 &nbsp;Based in **Tashkent, Uzbekistan** · speak **Uzbek, Russian, English**.
- 💬 &nbsp;Ask me about **frontend architecture, AI-assisted development, or building a startup from scratch**.
- 📫 &nbsp;Reach me at **[aidevix.uz](https://aidevix.uz)** or on [LinkedIn](https://www.linkedin.com/in/sunnatbekyusupov/).
