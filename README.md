### Engineering practices

- **Architecture**: monorepos, App Router with SSR/ISR, same-origin API proxies, typed API layers, Redux Toolkit state design.
- **Real-time**: Socket.io matchmaking, live code sync, chat and anti-cheat heartbeat watchdogs.
- **Security**: httpOnly JWT with refresh rotation, CSRF protection, TOTP 2FA, rate limiting, CAPTCHA and breached-password checks.
- **Quality**: GitHub Actions CI, Playwright E2E across Chromium, Firefox and WebKit, Jest and Vitest, strict TypeScript, ShellCheck and bats.
- **Operations**: Sentry, health-checked deployments on Railway and Vercel, Docker, EAS builds and OTA updates.
- **Product**: i18n for uz, ru and en, accessibility, SEO with structured data, payments integration.
